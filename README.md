# 个人用插件

AstrBot 私人实用插件，包含分群关键词语音、戳一戳响应、关键词表情回应、`/lishi` 调试检查命令、历史消息读取与 LLM 输出后处理等功能。

## 分群关键词语音

在 AstrBot 插件配置页面的 `group_keyword_voices` 中添加群聊规则。

每条规则包含：

- `group_id`：生效的 QQ 群号。
- `enabled`：本群独立开关，关闭后保留配置但不检测。
- `keywords`：触发关键词列表，消息包含任一关键词时触发。
- `audio_path`：命中后发送的本地语音文件位置。

该功能没有全局配置。未加入配置列表的群聊、私聊、关闭开关的群聊均不会触发。

配置 Aizo 语音时，将触发词填写到 `keywords`，并在 `audio_path` 选择已准备好的语音文件。英文关键词匹配不区分大小写。

支持在配置界面选择 `mp3`、`wav`、`amr`、`silk`、`ogg`、`m4a` 文件。文件被移动或删除后不会发送语音，日志会记录缺失路径。

从 v1.2.0 升级时，需要删除旧的 `group_keyword_replies` 配置，并在 `group_keyword_voices` 中重新选择语音文件。
